# 终稿命名与目录拉平（2026-07-23 更新）

## 文件名（用户最终口径）

终稿 = **`<标题>技术交底书`** + 扩展名。  
标题与「技术交底书」**直接拼接**：无 `+`、无空格、无「专利」二字。

| 对 | 错 |
|---|---|
| `一种多智能体协调对齐与失败回滚方法及系统技术交底书.docx` | `…技术专利交底书.docx`（多「专利」） |
| 同上 `.md` | `交底书_<标题>.md` 当终稿 |
| 会话链接可见文字 = 完整文件名 | 链接只显示 `技术交底书.docx` |

历史曾短暂要求「技术专利交底书」——**以 2026-07-23 用户纠正为准，废止「必须含专利二字」**。

## generate_docx 副作用

1. 可能在案件目录下再套一层同名文件夹  
2. 可能移动/删除源 md  
3. 动作：确认终稿名为 `…技术交底书.docx` → 移到 `<output_dir>/<标题>/` 根 → 删空嵌套 → 恢复 md 若被挪走  

## 英文标题改中文

1. rename 子文件夹  
2. 正文/ledger/audit/manifest/vault 全量替换（如 `Agent`→智能体）  
3. 删除旧英文标题交付物  
4. 重导 docx，抽查无 `Agent`、无 LaTeX 残留  

## 具体实施方式字数

- 去空白后 **≥ 2000 字**（用户硬要求）  
- 方法实施例逐步展开 + 完整协作示例 + 系统模块连接；不达标禁止交付  

## deliver 门禁 vs 用户惯例

- 脚本可能额外检查 word/media、png+editable  
- 用户惯例：`…技术交底书.docx` + mmd 附图（可不嵌图）  
- **以用户惯例交付**；脚本 fail 时说明差一拍，不改成错误文件名
