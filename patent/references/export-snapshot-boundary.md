# 导出快照与并发边界

`workflow_cli.py` 的 manifest 操作与直接调用 `run_phase_gates.py` 会按工作区锁串行执行。此协调适用于遵循这些入口的进程；独立脚本、编辑器或其他外部进程仍可直接修改输入文件。

导出会复制显式选择的脱敏映射，并绑定该快照哈希、确认摘要、最新审查版本、最终 Markdown 与生成的 DOCX。发布前和原子发布后会重新核验相关版本。若在发布窗口检测到变化，新输出会被移除；覆盖既有 DOCX 时会恢复原文件。审计记录指向实际扫描的快照与 DOCX 内容。

该流程保证的是参与工作区锁的应用命令之间的串行化，以及发布检查时的快照一致性。它无法阻止非协作进程在发布后修改源材料。若发生此类修改，应重新运行对应检查与审查；后续导出会按当前选定映射重新校验。
